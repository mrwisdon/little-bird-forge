# battlefield — Little Bird Forge (Minecraft 1.20.1)

A Minecraft Forge mod that adds BF-style crewed vehicles with mouse-flown flight controls, turreted
weapons, ammunition management and HUDs. Everything in it is built from the project's own code and
procedurally generated art; no third-party assets are shipped.

## Requirements

| | |
| --- | --- |
| Minecraft | 1.20.1 |
| Forge | 47.4.20 |
| Java | 17 |
| Gradle | wrapper 8.8 (`./gradlew`) |
| Mappings | official |
| Mod id / version | `battlefield` / 0.1.0 |

## Build, test and run

```bash
./gradlew compileJava              # fast compile
./gradlew test                     # JUnit 5 suite (pure rules: flight maths, weapons, magazines, HUD layout)
./gradlew build                    # resources + reobf + tests + jar
./gradlew runClient                # dev client
./gradlew runServer --nogui        # dev server
```

`./gradlew build` finishes with the `syncLocalMods` task, which copies the reobfuscated jar to
`local_mods_dir` in `gradle.properties` (a PCL2 version-isolated instance on the Windows side). Delete
that property to build without touching a game install.

## What is in it

**Aircraft** — Little Bird light helicopter (four seats, collective/roll on the mouse, miniguns and
70mm rocket pods) and AH-64 Apache (pilot/gunner, chain gun turret, rocket bay, TOW missiles).

**Ground vehicles** — M1A5 main battle tank (120mm main gun with AP/HE shells, coaxial machine gun,
smoke discharger) and EBAA Wildcat IFV (30mm autocannon, ATGM).

**Systems** — server-authoritative weapons with hitscan and projectile rounds, two-stage magazines
(ready rack + reserve, reload and resupply cooldowns), ammunition crate resupply, per-vehicle HUDs
(weapon slots, ammunition, reload/resupply clocks, hull condition) and a shared cockpit/exterior
camera family.

## Repository layout

```
src/main/java/io/github/littlebird/   mod code (client, entity, entity/weapon, entity/ground, network, registry, data)
src/main/resources/assets/battlefield/  textures (procedural), models, lang (en_us / zh_cn), sounds
src/test/java/                         JUnit 5 suite for the pure-rule classes
docs/plan/                             design notes, plans, per-stage logs and the evidence archive
models/                                standalone Python model/STL export of the ground units
tools/                                 texture generator scripts
```
