# 肩射视角（第三人称越肩）——参考图理解与设计草案

状态：**仅分析，未实现**（用户明确要求先不做）。
取证：把参考截图裁三块放大观察（准星区 / 机体区 / 载具 HUD 条），裁图存于 .codex-tmp/ref_*.png（临时件）。

## 1. 参考图里的视角是什么

| 维度 | 观察结果 |
| --- | --- |
| 相机位置 | 在载具**后上方并偏向一侧**（图中为左肩），距离较近 |
| 相机朝向 | **锁定机头轴线**，没有自由视角；准星固定在屏幕中央附近 |
| 机体占屏 | 机身沿画面**右下对角线**铺开并被屏幕边缘裁切，即机体被刻意推出画面中心 |
| 高度 | 明显高于机身轴线：能看到机背蒙皮、座舱盖与机翼上表面（俯视机体） |
| 准星形态 | **点阵包线**：左右各一簇点阵 + 中央一个点 + 水平虚线（不是实心十字） |
| HUD | 全套保留：武器名与弹药（九头蛇-70 火箭巢 014、∞）、载具俯视图标 + 健康 100 + 维修、干扰弹 100、左下小地图、右侧击杀信息 |
| 载具 | 图中是 **F-35E 黑豹** 挂 **九头蛇-70 火箭巢**（14 发），不是直升机 |

结论：这就是**越肩（over-the-shoulder）追尾视角**——本质不是改变朝向，而是
用「横向 + 向上」的相机偏移把机体让出画面中心，让瞄准区（准星周围）保持干净。
它不是电影化干净视角：HUD 全保留。图里的取景来自战机追尾相机，但取景逻辑可以直接搬到小鸟直升机。

## 2. 映射到本模组要实现什么（草案，待确认后再动手）

### 2.1 触发

- 第三人称下**按住鼠标右键**进入肩射，松开回到普通第三人称；
  （可配置改成一次按键切换。右键目前在驾驶时是空的——我们已取消交互事件，所以无冲突。）
- 舱内视角（C）与肩射互斥：肩射属于第三人称家族。

### 2.2 相机偏移量（首版建议值，需游戏内实测）

| 参数 | 建议初值 | 说明 |
| --- | --- | --- |
| 横向偏移 | 1.2 ~ 2.0 格（左肩为负/正待定） | 决定机体偏到哪一侧、偏多少 |
| 高度偏移 | 0.4 ~ 0.8 格 | 略高于机身轴线，形成俯视机体 |
| 距离 | 3.5 ~ 5 格，并**固定** | MC 的第三人称距离受滚轮控制，肩射需要固定值 + 最小距离，避免机身贴到近裁剪面 |
| FOV | 沿用 third_person_fov_multiplier | 肩射不单独给一套 FOV（可加开关） |

### 2.3 实现路径（两条，建议先走第一条）

1. **复用现有的客户端专用 `positionRider` 偏移**：第三人称相机是绕「玩家」而不是绕载具的，
   把隐身的乘员横向/上移，载具相对就会偏到另一侧——正是肩射要的构图。无 Mixin、改动最小，
   与舱内视角用的是同一套机制（已在本项目验证可行）。代价：客户端乘员位置与服务端相差该偏移量。
2. Mixin 进 `Camera#setup`：真正意义上的相机偏移，最正统，但需要给项目引入 Mixin 基建与配置文件。

### 2.4 顺带可以做（同一张图带来的风格项）

- 准星从「红十字 + 黄菱形」改成**点阵包线 + 中心点**（更接近参考图）。
- HUD 增加「武器名 + 弹药」标签（如 九头蛇-70 火箭巢 014）与载具俯视图标 + 耐久条。

## 4. 实施结果（已落地）

- 触发方式：按住右键；偏移：左肩 1.6 格 / 抬高 0.6 格；实现走 positionRider（无 Mixin）。
- 配置项：view.shoulder_view / shoulder_offset_blocks / shoulder_height_blocks。
- 未做：固定距离（仍受原版第三人称缩放影响）；准星点阵化的参考图还提示了「武器名 + 弹药」HUD 标签，未做。

## 5. 武直（AH-64）也已接入（2026-09-11 追加）

- 范围：**只给后座驾驶员**（`ApacheEntity.positionRider` 里判 `ApacheSeat.PILOT`）；前座炮手保持原样，
  他用鼠标转炮塔，不进入肩射。
- 复用：同一套 `LittleBirdCameraMath.shoulderOffset/applies` 与同一组配置项（1.6 / 0.6），
  **未新增配置键、未引入 Mixin**；驱动在 `client/ApacheInput`（第三人称 + 按住右键）。
- 为什么直接可用：武直乘员模型本来就永久隐藏（`ApacheRiderRender`），所以位移乘员 = 位移相机。
- 复位：松开右键 / 切第一人称 / 开舱内视角 / 换座 / 离机（`endSession`、`resetClientPrediction`）都会清掉。
- 待实测：武直的第三人称距离被 `CameraDistanceMixin` 放大到 `apache_third_person_distance=9`，
  1.6 / 0.6 这两个为小鸟标定的偏移量对更大机身是否仍合适，需要游戏内看图。
