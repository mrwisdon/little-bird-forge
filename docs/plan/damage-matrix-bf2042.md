## 4. 关键结论

1. 反装甲手段收敛到 **TOW / AGM / 120mm AP**（3 发左右），火箭（15 发）与机炮（40-120 发）都是低效手段，符合 BF2042 的分工。
2. HE 比 AP 差（4 发 vs 3 发），历史上正确。
3. 机炮不能按"机炮 = 炮弹"一刀切：喷气 25mm 对重甲 0、小野猫 30mm 1、阿帕奇 30mm 2、Bradley 25mm 3。
   实现必须支持**逐武器的对重甲数值（0 合法）**，即方案 B（每件武器一条伤害行）。
4. 小野猫用 30mm 打坦克要打光整整一条 600 发弹链（120 伤 / 120 血）—— "对最重甲低效"的手感，需确认可接受。
