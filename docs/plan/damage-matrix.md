## 规则（唯一判定）

    damageTo(DamageType type, ArmorClass armor, float 普通伤, float 装甲伤)

        UNARMORED            -> 普通伤

## 三处需要你知道的不一致（历史遗留，不是这次的规则）

1. **小鸟机枪与阿帕奇链炮打"轮式步战"取的是反人员数值（14 / 8）**，而不是装甲数值。
   原因：这两件武器用"机型枚举"定价，步战不是飞机 -> 落到普通伤害档。后果：小鸟机枪 7 发就能打爆 90 血的步战。
   要修就再给它们补"轻甲/重甲"两档。

2. **火箭与导弹（TOW、AGM、空空）对地面目标取"普通"数值**，对飞机才取"飞机"数值。
   所以 TOW 打坦克 60/90、打飞机只有 20/40。反坦克弹头这个方向是对的，但它是"因为不是飞机所以取普通值"的副作用，
   不是显式设计。要显式化就得把这几个抛射体也接进装甲矩阵。

3. **溅射伤害走各自的一套**：hitscan 的溅射在 GroundWeapons 里按矩阵算；抛射体的溅射交给原版 explode 结算。
   两者对重甲的处理因此不完全一致。

## 覆盖审计（13 处 damageTo 调用点）

- 已走矩阵（4）：小鸟机枪、阿帕奇链炮 x2、GroundWeapons。
- 旧式（9）：全部是 SHELL 类（120mm、25mm、70mm 火箭、TOW、空空导弹及内部委托），
  免疫规则对它们本就不适用，故行为不变。
