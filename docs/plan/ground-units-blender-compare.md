## 2. 逐项差异（网图 -> 我的 rev2）

| 部位 | BF2042 M1A5 网图 | 我的 rev2 | 差距 |
| --- | --- | --- | --- |
| 炮塔前部 | 宽楔形：两块大斜面**颊甲**从炮塔顶前缘向炮盾收拢；炮盾与塔体连成一体 | 台阶状盒体 + 顶面斜板；炮盾是独立小方盒 | **大**：没有斜面颊甲，前部读成阶梯 |
| 炮盾/炮根 | 炮盾居中、明显外露，炮管穿出 | 小方盒，偏小 | 中 |
| 烟幕发射器 | 炮盾**两侧各一簇**（约 6 管），朝前 | 塔侧各 6 管，位置偏后、方向偏内 | 中：位置/朝向不对 |
| 炮长镜 + CITV | 塔顶前部两个明显方盒（炮长主瞄 + 车长独立热像仪） | 只有一个小方盒 | 中：缺 CITV |
| 塔侧 | 备用履带板（成排）+ 长条储物轨 | 无 | 中 |
| 尾舱 | 大开口储物篮，装满行包/备件 | 小篮 + 两个小箱 | 中：偏小 |

| 车体首部 | 宽浅首上斜面；两组长条 LED 大灯；中央橡胶挡板；拖钩 | 阶梯首部 + 两个小方灯 | 中 |
| 车尾 | 两个红色尾灯 + 发动机格栅 + 排气 + 拖缆 | 简单尾板 + 两个小灯 | 中 |

## 3. 已经对上的部分（不用改）

- 总体尺度：9.77 m 火炮向前 / 3.66 m 宽 / 2.44 m 至炮塔顶，与真实 M1A2 一致。
- 结构：每侧 7 对负重轮、前置诱导轮、后置主动轮、6 段侧裙、炮塔尾舱、120mm 炮（热护套+抽气装置+炮口）。
- rev2 已把车体压低（车顶 1.64 -> 1.52 m）、炮塔放大（高 0.80 -> 0.92 m、长 3.0 -> 3.4 m），纠正了上一轮"偏肥"。
- 炮塔宽度 2.72 m 已大于车体 2.46 m，与网图"炮塔外伸盖过车体侧"一致。

## 4. 结论

比例与结构基本对上；**剩下的差距集中在炮塔前部造型（颊甲/炮盾）与表面细节（ERA、灯组、附件、涂装）**。
"肥"的问题在 rev2 已明显缓解，下一步要做的是"细节像不像"，而不是继续改比例。

## 5. 下一轮建议（按性价比排序）

1. **炮塔颊甲**：给生成器加 yaw 斜板，把前部台阶改成两块斜面颊甲 —— 对"帅"影响最大。
2. **侧裙 ERA/面板线**：改贴图分区（不加几何、不超 3.66 m 宽），把方块阵列画进裙板区。
3. **塔顶炮长镜 + CITV 方盒**；**烟幕发射器移到炮盾两侧**。
4. **塔侧备用履带板 + 储物轨**；**尾舱加大**。
5. 车首大灯/橡胶挡板、车尾尾灯/格栅等小件补齐。
6. 涂装：仍不做具体迷彩/编号（无公开色值来源）。
